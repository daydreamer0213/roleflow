## 当前结论

- 默认路径已定义为“RoleFlow 专用 Edge（推荐）”，不需要 Edge Control。
- `%LOCALAPPDATA%\RoleFlow\BrowserProfile` 只保存并稳定复用浏览器登录资料；数据库等安装目录数据不会自动跨目录迁移。
- “使用当前 Edge（高级，需要浏览器连接组件）”只允许显式选择，且不会成为默认路径的自动 fallback。
- 两个固定 BOSS 页仍是基线；消息发现只有一个受控后台临时详情页例外。
- 用户启动工作区时可以有一次前台引导，之后所有产品工作都保持后台。
- 迁移显式、只复制并保留源；普通/静默卸载保留 profile，删除需要独立确认。
- 启动测试不再创建假的 `msedge.exe`；Edge Control 不进入普通安装包。
- 工作区会主动补齐专用 Edge 和固定 BOSS 页面；除启动引导外不抢占前台。
- 搜索页已登录但尚无关键词时，工作区现在先在后台补齐唯一消息页和工作台，再使用当前有效求职方案准备首个 A/B/C 关键词；准备成功后自动复检，不再要求用户点击“刷新工作区”。没有 onboarding 运行记录的旧数据也适用；已有 query 和城市、地铁、商圈等筛选不会被覆盖。
- 新装和覆盖升级都会显示安装位置选择页。升级默认带出上次安装目录，用户可以直接继续，也可以点原生“浏览”按钮更换程序目录；用户数据目录不随程序目录移动。
- 专用 Edge 本地冷/热短测均只有一个浏览器根进程，但单空白页进程组私有内存约 0.83–0.92 GB；暂未发现 RoleFlow 重复启动浏览器的证据，也没有证据支持牺牲后台运行可靠性来增加省内存参数。
- 完整 JD 后增加岗位资格闸门，明确不符合实习/届别/在校要求的岗位不会进入推荐或沟通。
- 专用 Edge 已具备受限网络结果验证能力；能力或观察准备失败发生在点击账本之前。
- 消息发现已把招聘方沟通意图与消息话题拆开：只有正式面试邀约推进面试阶段，单纯提到“面试”不会被当成邀约。
- 消息结果现在显示 HR 原文或安全卡片摘要、岗位理解与既有分析结论，再显示本地回复草稿；已读与送达只计数，不逐条展示。草稿生成或自动保存不会触发平台写入。
- 已验证的附件简历请求卡片现在显示为 BOSS 人工待办；同一轮的纯文字仍独立生成草稿，平台竞争提示不进入模型。未知、位置或面试卡片在缺少真实结构证据时继续安全停止。
- 回复草稿现在可以直接编辑并在本机自动保存；复制或标记“已手动发送”会直接采用当前文字完成本地学习。点击单条或批量确认时，当时的目标、草稿版本和文字会成为不可变发送授权，由固定后台消息页串行执行，不再二次确认。
- 只有用户真正改过且仍启用的回答会作为后续同类沟通口径；未修改模型草稿不是权威事实，事实提取失败也不会丢失用户改好的完整回答。
- 新增“我的沟通资料”，可修改或删除当前事实、编辑或停用已记住的回答，并查看自然语言事实修改历史。
- 岗位主卡现在先给推进结论，再自然显示岗位职责、公司与机会、匹配、薪资和需要确认的问题；内部决策来源仍在展开明细。
- 首次分析失败后重试成功的岗位会保留失败历史，同时显示“失败后已解决”；当前未解决和流程体检不再被历史失败污染。
- 岗位判定的生产决策已经冻结为继续使用二维表。43 条可比较样本中 38 条一致、5 条积分更保守、硬边界逃逸 0；仓库没有人工确认标签或同岗位重复模型样本，因此不能声称积分准确率或稳定性更差，也不再把“是否切换积分”列为近期开发任务。
- “求职体检”只统计用户确认已投、已验证发起沟通或确认已发送回复的岗位。默认 30/50/70 分别给初步观察、可比较结论和正式诊断，三项可按用户求职强度调整且必须严格递增。
- 每个求职动作至少等待 48 小时，周末截止顺延到周一；岗位成熟后若出现新的已读，“已读未回”从该次已读重新等待 48 小时。等待、未知、用户关闭/拒绝均不进入失败分母，明确回复、简历请求和面试邀请会立即显示。
- 每个真实求职动作永久绑定到发生时的策略轮次。用户在外部修改招呼语或求职策略后，可在本地点击“修改完成，开始验证新方案”；旧岗位和迟到结果仍更新旧轮，新动作进入新轮，不再按滚动批次混算或在 70 个时自动切池。
- 当前诊断只读当前轮；同方向的前后轮都达到各自 50 个成熟样本且历史边界可靠时，才展示描述性前后变化。方向变化显示不可比较，同时调整多项显示“无法区分单项影响”，不声称因果、准确率或效果提升。
- 阶段三现已按新设计直接生成一份完整、可编辑、自动保存的定向简历：用户只选源简历与方向，系统自动选取最多 5 个可信完整 JD，并用只读账本说明改了什么、为什么改、依据和修改原则。原简历与系统生成基线始终冻结；启用当前全文会创建新简历版本，并与新策略轮次在同一事务中生效或一起回滚。
- 定向简历现在会在自动保存后即时检查当前全文：占位内容、姓名或联系方式丢失、生成基线异常以及无当前依据的新日期、数字或联系方式会阻止启用；改动过少、篇幅明显增加和用户继续编辑只做提醒。用户修改后的当前全文检查通过即可直接启用，不增加二次确认；历史已启用版本不重新判断或改写。
- 模拟面试现在默认进入“简历通用面试”：不需要岗位或面试邀请，只冻结当前启用简历、全局/经历范围内的有效回答与事实，并让每道题显示对应简历依据；追问仍必须引用用户刚才回答中的真实片段。原岗位上下文面试保留为可选“岗位专项面试”，才会使用完整 JD 与适用的岗位/公司口径。
