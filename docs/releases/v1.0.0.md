# RoleFlow v1.0.0

## 正式发布

- RoleFlow 第一阶段主流程已经完成真正新用户路径的人工验收，可从模型设置和简历导入一路完成搜索方案、岗位筛选、清单确认、连续沟通与只读消息发现。
- 连续沟通保持后台执行，不再通过 `Page.bringToFront` 激活 BOSS 标签；工作流仅在状态变化时按需更新，避免高频整页闪烁。
- 直接批量清单、工作流复核页和后端创建接口使用同一套资格判断，任何历史已点击岗位都不会再次进入新清单。
- 岗位身份、固定标签绑定、登录与风控检查、网络结果取证、单次点击和结果不明确即停止规则保持不变。

## 下载

- 普通 Windows 用户请下载 `RoleFlow-Setup-1.0.0.exe`。
- 使用同页的 `RoleFlow-Setup-1.0.0.exe.sha256` 校验安装器完整性。
- `RoleFlow-v1.0.0-portable.zip` 是高级免安装版；GitHub 自动生成的 Source code 压缩包不是安装程序。

## 验证与限制

- 除 `startup_scripts_smoke.js` 外的 96 组安全离线检查已通过；这些检查不会访问 BOSS 或执行真实沟通。该启动测试会临时编译名为 `msedge.exe` 的本地桩程序并触发 360 告警，因此本轮没有重跑。
- 真正新用户路径的人工验收已完成，主流程完整跑通；真实连续批次保持串行执行、逐岗位核验，停止项没有自动重试。
- 只读消息发现已完成，无法和候选岗位可靠对应的会话会保留为“需要人工处理”，不会生成错误草稿。
- 安装器尚未代码签名，Windows 可能显示信誉或 SmartScreen 提示。
- 标准安装器不分发 Edge Control 扩展和桥接；启动前仍需按 README 准备现有本地连接。
