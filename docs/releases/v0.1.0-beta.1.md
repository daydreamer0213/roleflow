# RoleFlow v0.1.0-beta.1

这是 RoleFlow 的首个公开 Beta，面向本地试用、代码审阅与离线流程验证。

## 本次包含

- TXT、Markdown、DOCX、PDF 简历解析与候选人画像。
- 搜索方案生成、岗位列表采集、完整 JD 读取、去重与本地持久化。
- 结合硬性条件、语义证据和风险信号的四层岗位建议。
- 可恢复的工作流、用户确认后的不可变沟通批次，以及失败即停止的安全边界。
- BOSS 消息页只读发现与本地草稿工作流。
- 本地仪表盘、操作文档和 93 组离线检查。

## 验证

- `npm.cmd test`：93 组离线检查全部通过。
- 测试不访问 BOSS，不发送消息，也不执行真实沟通。
- 发布包不包含真实简历、账号凭据、API Key、岗位数据库、浏览器配置或运行日志。

## 已知限制

- 当前为 Beta，不承诺 BOSS 页面适配在平台改版后仍然有效。
- 真实消息读取与沟通链路尚未完成人工端到端验收；离线通过不能替代真实页面验收。
- 默认普通 Edge 模式依赖已安装且连接健康的 Edge Control 扩展和桥接；发布包不内置该桥接。
- 便携 CDP 模式是显式兼容入口，不会由普通 Edge 模式失败后自动启用。
- 当前以 Windows 和 Node.js 22 为主要运行环境。
