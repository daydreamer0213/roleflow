# RoleFlow v0.1.0-beta.4

这是 RoleFlow 第一阶段 Wave 4 有条件收口后的 Windows 公开 Beta。

## 普通用户下载

- 普通 Windows 用户请下载 `RoleFlow-Setup-0.1.0-beta.4.exe`。它提供安装进度、开始菜单、可选桌面快捷方式和 Windows 卸载入口。
- `RoleFlow-Setup-0.1.0-beta.4.exe.sha256` 用于校验安装程序完整性。
- `RoleFlow-v0.1.0-beta.4-portable.zip` 是高级免安装版，保留源码、便携运行和故障恢复入口。
- GitHub 自动生成的 Source code 压缩包不是安装程序。

## 本版改进

- 增加标准 Windows 安装器、隐藏终端启动器、轻量环境自检和安全卸载；默认保留本地用户数据。
- 首次启动先进入模型设置；模型连接成功后引导填写简历。
- 模型设置在桌面端改为左右布局，并增加 DeepSeek 开放平台和下一步入口。
- 简历解析改为持久化后台任务，显示阶段、耗时、失败原因和可恢复状态。
- 今日任务、岗位筛选和正在沟通页面改为结果与下一步导向，剩余工作按真实待办计算。
- 继承搜索页条件时不再因本地城市为空阻塞扫描；筛选方案区分平台继承条件和本地精细筛选。
- 沟通详情复用固定搜索标签，不再占用消息标签。
- 只读消息发现可保留尚未关联本地投递记录的 HR 主动机会。
- 可恢复的点击前读取故障允许一次受限恢复；登录、风控、目标漂移和点击后结果不明仍立即停止。
- 标准安装目录不再包含 `Install.bat`、`Start.bat` 和便携扫描脚本；这些高级入口只保留在源码与便携 ZIP。

## 验收证据

- 正式 Gate D 使用稳定的 `trusted_pane` 主线完成 5 个关键词。
- 全新空 baseline 获得 51 个唯一岗位，51/51 详情成功，51/51 具有完整 JD，详情失败 0。
- Dashboard 完成 12 个页面状态 × 4 个视口，共 48 个页面状态的离线矩阵验收。
- 消息页离线验收覆盖一条未关联的 HR 主动机会；没有启动真实消息发现或提交表单。
- 发布候选完整离线套件已通过 97 项检查；标签发布还会在同一提交的 GitHub Windows runner 上重新执行。
- 本轮没有创建新的真实沟通批次，没有发送消息，也没有执行申请。

Wave 4 仍是有条件通过，Wave 5 继续暂停。

## 已知限制

- 安装程序尚未代码签名，Windows 可能显示信誉或 SmartScreen 提示。
- 当前安装器不公开分发 Edge Control 扩展和桥接，因为项目尚无可验证的再分发许可；全新电脑仍需按说明单独准备浏览器连接组件。
- 自动沟通的真实人工端到端验收尚未完成；没有用户明确授权时不得执行真实沟通或发送。
- 当前验收账号的消息页为空，出现真实会话后的少量只读抽样仍待完成。
- Gate D 的 51 条人工质量标签仍待标注，不能把当前技术分布解释为已确认的精确率或召回率。
- 正式 Gate D 后修复的模型 evidence 超长问题尚待下一次全量扫描验证批量稳定性。
- `search_page_api` 是后续独立拓展，不属于当前产品主线。
