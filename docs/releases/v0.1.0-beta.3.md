# RoleFlow v0.1.0-beta.3

这是 RoleFlow 第一阶段 Wave 4 条件收口后的公开 Beta，继续面向本地试用、代码审阅与离线流程验证。

## 相对 beta.2 的更新

- 正式主线继续使用稳定的 `trusted_pane` 读取岗位右栏详情；未切换到实验性详情链路。
- 增加账号级 BOSS 访问安全账本，使全新业务 baseline 仍能继承同一账号的访问预算和风控状态。
- 收紧 `understandJob` 的 JD 证据契约修复：不增加模型调用，只在内容可证明为连续 JD 原文时限制超长摘录，来源不明的内容仍由原校验拒绝。
- 更新 Wave 4 条件收口报告和公开版本说明。

## 验收证据

- 使用全新空 baseline 完成 5 个正式关键词。
- 获得 51 个唯一岗位，51/51 个右栏详情成功，51/51 个岗位具有完整 JD。
- 5 个扫描目标、扫描运行和批次均正常完成；没有登录丢失、风控或页面身份漂移。
- Dashboard、自动沟通入口和空消息页只读状态通过人工验收。
- 本轮没有创建沟通批次，没有发送消息，也没有执行申请。
- 本地已通过 93 组离线检查；发布标签只会在同一提交的 GitHub Windows runner 也通过 93 组检查后创建。

## 已知限制

- 当前仍是 Beta，不承诺 BOSS 页面改版后的持续兼容性。
- 51 条 Gate D 人工标签尚未完成，因此不能把技术评测分布解释为已确认的精确率或召回率。
- 新账号的真实消息页为空；有真实会话后的只读抽样仍待验收。
- 真实自动沟通的人工端到端验收尚未完成，任何沟通或发送仍需用户明确授权。
- 实验性详情链路不属于当前正式主线，留待后续独立拓展。
- 当前以 Windows 和 Node.js 22 为主要运行环境。
