# RoleFlow v1.2.1

## 本版重点

- 首次简历处理完成后，RoleFlow 会从已保存方案中选择首个有效关键词，在后台为固定 BOSS 搜索页补上关键词。用户可以直接在这个有关键词的页面继续选择城市、地铁、商圈等精细条件，再回到工作台开始岗位发现。
- 今日任务改为在原页面提交启动请求，服务端检查浏览器期间不会让工作台页面进入自等待。慢网络下，岗位列表的等待窗口也更长；内容一旦出现就立即继续，不会固定多等。
- 用户人工处理沟通结果不明确的项目后，可以从原沟通批次恢复，已经确认的结果不会被重新执行。
- 两轮岗位发现之间仍默认建议等待两小时。如果本轮候选明显不足，用户可以点击“提前开始下一轮”，阅读风险提示后仅为当前请求确认提前开始。

## 安全与兼容性

- 提前开始只解除本次请求的两小时间隔。每日轮次上限、访问额度、随机等待、固定标签页、登录检查和风控即停仍然有效。
- 搜索页已有关键词、方案正在复用、页面身份异常、登录失效或出现风控时，系统不会覆盖现有条件或继续访问。
- 本版不改变数据库格式。覆盖安装会继续复用 `%LOCALAPPDATA%\RoleFlow\BrowserProfile` 中的专用 Edge 登录资料；简历、模型 Key、岗位数据库、日志和报告仍不会进入发布包。

## 下载

- 普通 Windows 用户下载 `RoleFlow-Setup-1.2.1.exe`。
- 使用同页的 `RoleFlow-Setup-1.2.1.exe.sha256` 核对安装器完整性。
- `RoleFlow-v1.2.1-portable.zip` 面向需要便携包的高级用户；GitHub 自动生成的 Source code 压缩包不是安装程序。

## 验证与限制

- v1.2.1 最终候选注册 132 项离线检查。标签发布会在精确提交上重新执行全部检查；这些检查使用 fixture、假浏览器和临时数据库，不访问真实 BOSS，也不产生真实外部写入。
- 安装器尚未代码签名，Windows 可能显示信誉或 SmartScreen 提示。
- 未取得真实 DOM 证据的位置确认、面试排期及未知消息卡片仍会停止，不会猜测点击或发送。
- 真实沟通仍只限用户当次确认的固定岗位和文字；历史验收授权不会自动延伸到新的沟通批次。
