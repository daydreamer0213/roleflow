# RoleFlow v1.3.2

## 本版重点

- 修复专用 Edge 后台焦点模拟刚启用就因连接关闭而失效的问题，使它覆盖目标复核和唯一一次点击；不抢占前台。
- 连接中途断开后不会静默换连接继续点击；启用失败也会正确清理，不让失败状态挡住同一运行里的后续操作。沟通和回复填入/发送共享该修复。
- 记录有限且脱敏的点击回执、页面状态和仍在等待的请求数量，便于区分点击与结果观察问题。诊断不保存聊天正文、私密 URL 或请求参数，也不代替平台成功证据。
- 沟通结果不足时显示“未能确认本次沟通结果”，明确不等于发送失败；系统仍停止，不自动补点或重试。

## 安装目录与资料

安装器默认目录不包含版本号，升级沿用上次选择。若旧验收目录名含 `v1.2.0`，不表示当前程序仍是该版本；建议使用固定路径，例如 `D:\Apps\RoleFlow`，不要每次升级换目录。

安装版资料仍在 `%LOCALAPPDATA%\RoleFlow\Data`，浏览器登录资料仍在 `%LOCALAPPDATA%\RoleFlow\BrowserProfile`。本版不会清空或自动搬迁它们。换安装目录不等于无记录新用户；首次与再次使用验收应明确隔离环境，第二轮继续使用第一轮保存的资料。

没有新增依赖或数据库迁移，不改变筛选、节奏、访问额度、用户确认和一次点击边界。

## 下载

- Windows 安装器：`RoleFlow-Setup-1.3.2.exe`。
- 完整性校验：`RoleFlow-Setup-1.3.2.exe.sha256`。
- 高级便携使用：`RoleFlow-v1.3.2-portable.zip`；Source code 不是安装程序。

## 验证边界

本版注册 144 项离线检查，新增双本地标签页的实际 Edge 生命周期回归；发布流程在精确标签提交上重新验证并构建。测试使用本地数据与隔离浏览器，不访问真实 BOSS、不执行真实沟通。

已复现并修复浏览器生命周期缺陷，但不能据此断言它是此前真实 BOSS 中断的唯一原因。首次安装和再次使用的两轮真实人工验收由用户操作，尚不宣称通过。

安装器尚未代码签名，Windows 可能显示信誉或 SmartScreen 提示。
