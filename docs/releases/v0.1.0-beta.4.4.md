# RoleFlow v0.1.0-beta.4.4

## 本版修复

- 暂停或中断的普通 Edge 沟通批次恢复前，会重新检查固定标签页和原筛选范围；检查失败不会启动沟通进程。
- 已确认的 BOSS `friend/add` 成功响应，即使页面同时出现通用中间弹窗，也会保留为成功结果，不会触发自动重试或第二次点击。

## 验收与限制

- 完整离线套件通过：`All 97 offline checks passed.`。
- 真实批量沟通仍待用户按页面显示的不可变岗位逐项人工验收；离线通过不等同于真实页面已验收。
- 安装器尚未代码签名，Windows 可能显示信誉或 SmartScreen 提示。
