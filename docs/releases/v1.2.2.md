# RoleFlow v1.2.2 候选说明

## 本版重点

- 点击暂停后，页面先显示“正在暂停”；系统会在下一次安全的浏览器动作前真正停下。只有完全停止后才显示“本轮已暂停”，避免用户以为已经停住、实际仍在继续读取岗位。
- 暂停或可恢复中断后再次继续，系统会先比较开始时与当前 BOSS 搜索条件。条件没变就恢复原批次；条件已变则让用户选择按新条件重新开始本轮，或继续使用开始时的条件。
- 按新条件重开仍属于当天同一轮，不额外消耗轮次号。旧批次作为历史保留但不再参与当前结果，新关键词和筛选条件会进入新批次。
- 如果选择页出现后用户又修改了一次条件，系统只刷新选择内容，不会误用过期选择启动扫描。
- 岗位卡片数量严格遵守本轮冻结上限；条件变化后的卡片不会混入原批次。
- 运行错误先说明发生了什么、当前影响和建议操作；内部错误编号与请求编号保留在可展开的技术信息中。

## 安全与兼容性

- 本版不改变数据库格式、岗位分析规则、模型调用策略或发布包隐私边界。
- 岗位发现仍是只读操作。登录失效、风控、固定页面丢失、岗位身份不一致或页面条件异常时停止，不自动点击沟通、填写、发送、投递或申请。
- 安装包继续复用 `%LOCALAPPDATA%\RoleFlow\Data` 与 `%LOCALAPPDATA%\RoleFlow\BrowserProfile`；这些用户数据不会进入发布资产。

## 验证状态

- 当前文件描述 source candidate，不代表 v1.2.2 已公开发布。正式下载入口仍是 v1.2.1。
- 候选注册 132 项离线检查；发布前必须在精确最终提交上重新全部通过，并验证便携包、安装器暂存区和 SHA-256。
- 所有自动检查使用 fixture、假浏览器和临时数据库，不访问真实 BOSS，也不产生真实外部写入。
- 安装器尚未代码签名，Windows 可能显示信誉或 SmartScreen 提示。
