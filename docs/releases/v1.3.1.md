# RoleFlow v1.3.1

## 本版重点

- 筛选方案增加默认关闭的“接受兼职”。岗位标题、明确职责和岗位薪资中的小时计价可提供兼职证据；明确全职、全兼均可、否定描述或加班时薪不会被机械误排除。
- 新方案不再预填开发期间的薪资范围；未设置范围时薪资不参与限制或排序惩罚。已保存的用户范围继续保留，可自行清空；BOSS 页面选择的薪资档独立生效。
- “继续沟通”不再要求搜索页的城市、地铁等条件等于扫描时的条件。仍只处理已确认岗位清单，核对岗位身份，遇到结果不明确时停止，不重复发送。
- 沟通中断会显示可理解的原因、影响和下一步，不再看起来像按钮没有反应。
- 初次准备搜索页时同步补齐消息页，并带入求职方案关键词；重启后的空页可恢复未完成本轮的关键词和条件，已有页面不覆盖。
- 补齐尚未创建沟通批次时，中断与待复核状态下的“结束本轮”入口，保留已有结果；新增猴子产品图标，安装与升级均可选择安装位置。

## 数据与兼容

标准安装版继续使用 `%LOCALAPPDATA%\RoleFlow\Data` 和独立浏览器登录目录；不会清空简历、方案、岗位或消息记录。已有薪资条件不自动删除，用户可在“今日任务 → 调整筛选条件 → RoleFlow 本地精筛”清空后保存。

没有新增依赖、数据库迁移或生产岗位判定路线切换，不改变 48 小时/周末顺延、30/50/70 反馈门槛及真实发送的当次确认要求。

## 下载

- 普通 Windows 用户：`RoleFlow-Setup-1.3.1.exe`。
- 完整性校验：同页 `RoleFlow-Setup-1.3.1.exe.sha256`。
- 高级便携使用：`RoleFlow-v1.3.1-portable.zip`；Source code 不是安装程序。

## 验证边界

版本注册 143 项离线检查；发布流程在精确标签提交上重新运行并构建资产。开发检查使用示例数据、临时数据库和模拟浏览器，不访问真实 BOSS，不调用真实模型或产生真实沟通、发送、投递。离线通过不代表真实平台全流程已经复验。

安装器尚未代码签名，Windows 可能显示信誉或 SmartScreen 提示。
