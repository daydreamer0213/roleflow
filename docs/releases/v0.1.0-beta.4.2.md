# RoleFlow v0.1.0-beta.4.2

这是 beta.4.1 新用户人工验收后，对当前路径中真实触发问题的整改候选版。

## 普通用户下载

- 普通 Windows 用户请下载 `RoleFlow-Setup-0.1.0-beta.4.2.exe`。
- `RoleFlow-Setup-0.1.0-beta.4.2.exe.sha256` 用于校验安装程序完整性。
- `RoleFlow-v0.1.0-beta.4.2-portable.zip` 是包含固定 Node.js 的高级免安装版。
- GitHub 自动生成的 Source code 压缩包不是安装程序。

## 本版改进

- 共享模型厂商和 API Key 现在只需一次“测试连接并保存”，会按顺序验证深度分析和批量筛选；两项都成功后才原子保存。
- “下一步：填写简历”始终可见，主模型尚未完成验证时会明确禁用并提示原因。
- 岗位筛选页展示本轮实际冻结的关键词，并单独显示方案候选词数量；没有裁剪候选词库或降低召回。
- 本轮概览直接显示搜索目标采集进度和完整 JD 进度，轮询期间会持续更新。
- 自动沟通改为一次浏览器级点击，并结合受限的 Edge 网络日志和页面状态判断结果；结果不明时立即停止且不自动重试。
- API Key 回显会在进入页面和日志前遮蔽；BOSS 网络证据只接受可信 origin，并限制为最多 12 条脱敏记录。

## 验收证据

- 完整离线套件通过：`All 97 offline checks passed.`
- 模拟 UI 严格门检查 12 个页面、4 种视口，共 48 张截图；控制台、页面、请求、外部访问和横向溢出错误均为 0。
- BOSS 相关离线检查全部使用 fake browser，没有访问真实 BOSS。
- 本版没有抓取新岗位，没有恢复或重放旧沟通批次，没有点击真实“立即沟通”，没有发送消息或申请岗位。

## 已知限制

- 安装程序尚未代码签名，Windows 可能显示信誉或 SmartScreen 提示。
- 安装器不公开分发 Edge Control 扩展和桥接，因为项目尚无可验证的再分发许可；全新电脑仍需按说明单独准备浏览器连接组件。
- 自动沟通的真实单岗位端到端稳定性仍待用户针对不可变样本另行授权验收，不能把离线通过解释为线上已修复。
- 旧真实沟通批次 #1 保持原样，没有恢复、解决或重放。
- 当前岗位详情主线仍只使用 `trusted_pane`；`search_page_api` 是后续独立拓展，`standalone_detail` 不启用。
- Wave 5 继续暂停。
