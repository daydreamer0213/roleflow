# RoleFlow v0.1.0-beta.4.1

这是 beta.4 的启动阻塞热修版本。beta.4 保留为历史证据，不覆盖原标签和安装包。

## 普通用户下载

- 普通 Windows 用户请下载 `RoleFlow-Setup-0.1.0-beta.4.1.exe`。
- `RoleFlow-Setup-0.1.0-beta.4.1.exe.sha256` 用于校验安装程序完整性。
- `RoleFlow-v0.1.0-beta.4.1-portable.zip` 是包含固定 Node.js 的高级免安装版。
- GitHub 自动生成的 Source code 压缩包不是安装程序。

## 本次修复

- 修复 `scripts/start-edge-control.ps1` 在 Windows PowerShell 5.1 中无法解析、导致标准安装后首次启动立即失败的问题。
- 脚本改为带 UTF-8 BOM，并移除会参与 PowerShell 字符串语法的中文弯引号。
- 增加真实 PowerShell 解析回归检查，发布前逐一解析随包的 `.ps1` 脚本。

## 验收证据

- 原 beta.4 安装目录稳定复现启动脚本 `ParserError`。
- 回归检查在修复前失败，修复后通过。
- `start-edge-control.ps1 -CheckOnly` 已从语法错误进入真实的浏览器连接状态检查。
- 完整离线套件、安装器构建和公开安装验收以本标签的 GitHub 发布工作流为准。
- 本次没有访问真实 BOSS，没有沟通、发送消息或申请。

## 未在本次修改

- 错误弹窗的信息层级和具体操作指引继续保留在本轮人工验收问题台账，等待完整验收后统一整改。
- Edge Control 不随安装器公开分发的许可与安装引导边界没有改变。
- `trusted_pane` 仍是当前主线；`search_page_api` 仍是后续独立拓展。
- Wave 5 继续暂停。
