# RoleFlow v1.3.0

## 本版重点

- 新增“无回复跟进”工作区：系统从本地记录中找出已过等待期且仍无回复的岗位，生成可编辑、可自动保存的跟进草稿；用户仍需逐条或批量确认后才会进入既有后台串行发送流程。
- 岗位现在可以归档和恢复。归档岗位不会继续进入待办或旧入口操作，用户可随时恢复；岗位列表还可以导出为 CSV，便于在表格中整理和复盘。
- 消息草稿增加本地质量检查：减少近期重复表达，并阻止模型文字加入未经用户确认的个人经历或数字。发送前会按当前有效事实再检查一次；用户亲自编辑的文字仍直接视为确认，不增加二次确认。
- 定向简历启用前会重新核对冻结原简历、当前事实和适用回答，并严格绑定当前搜索方案。启用失败保留用户已经编辑的全文，成功后才原子创建新简历版本和新的策略轮次。

## 体验与兼容性

- 首页增加需要跟进的数量入口；岗位归档、CSV 导出、跟进草稿和定向简历错误都使用可直接理解和处理的页面提示。
- 数据库会按既有流程先备份再升级到 schema v28；不会改写历史已启用简历，也不会静默删除旧岗位、消息草稿或求职记录。
- 本版不改变已经冻结的岗位二维表判断、48 小时及周末顺延、30/50/70 诊断门槛或每日岗位发现节奏。

## 安全与数据边界

- 岗位发现、状态统计和跟进候选计算仍以本地记录和只读页面信息为基础。登录失效、风控、固定页面丢失、岗位身份不一致或结果不明确时停止。
- 归档和导出只修改或读取本地数据；CSV 不包含简历正文、模型 Key、Cookie 或 BOSS 登录资料。
- 无回复跟进和消息回复不会后台定时发送，也不会绕过用户当次确认。历史验收或历史批次的发送授权不会自动延伸到新批次。
- 安装包继续排除用户简历、模型 Key、SQLite 数据库、日志、报告、浏览器 profile 和 Edge Control bridge。

## 下载

- 普通 Windows 用户下载 `RoleFlow-Setup-1.3.0.exe`。
- 使用同页的 `RoleFlow-Setup-1.3.0.exe.sha256` 核对安装器完整性。
- `RoleFlow-v1.3.0-portable.zip` 面向需要便携包的高级用户；GitHub 自动生成的 Source code 压缩包不是安装程序。

## 验证与限制

- v1.3.0 注册 142 项离线检查；标签发布会在精确版本提交上重新执行全部检查，并重新构建便携包与安装器。
- 自动检查使用 fixture、假浏览器、纯渲染和临时数据库，不访问真实 BOSS，不调用真实消息模型，也不产生真实外部写入。
- 四组新增能力已经完成桌面端示例数据页面验收；最后一轮真实人工验收由用户安装公开安装包后独立完成，尚不能在发布前声称真实平台端到端通过。
- 安装器尚未代码签名，Windows 可能显示信誉或 SmartScreen 提示。
