# RoleFlow 同窗启动与登录就绪门禁设计

**日期：** 2026-08-05
**状态：** 已确认
**依赖设计：** `2026-08-05-portable-standalone-workflow-design.md`

## 1. 背景与问题

便携独立工作流已经能够通过项目专用 Edge、CDP `127.0.0.1:9222` 和项目本地工作台运行，不需要 Codex 或 Edge Control。

现有启动顺序仍有两个产品问题：

1. 工作台和项目专用 Edge 可能分别出现在不同浏览器窗口，用户需要来回寻找。
2. 启动后不会主动展示 BOSS 登录与搜索页就绪状态；只有用户点击“执行一轮”后，服务端预检才会提示未登录或页面无效。

第一次使用项目专用 Edge 时，独立的 `.runtime\edge-profile` 很可能尚未登录 BOSS。正常流程必须先引导用户登录，再允许启动继承模式。

## 2. 目标

`Start.bat` 完成启动后，只出现一个项目专用 Edge 窗口。该窗口包含：

- 一个承担 `BOSS-SEARCH` 角色的 BOSS 标签页；
- 一个 RoleFlow 工作台标签页。

工作台持续显示只读浏览器就绪状态。只有同时满足以下条件时，主继承模式的“执行一轮”按钮才允许使用：

- 项目专用 Edge 可连接；
- 能识别 `BOSS-SEARCH` 标签页；
- BOSS 登录有效；
- 当前页是有效的岗位搜索结果页；
- 原有候选人资料、Search Plan、匹配偏好卡、运行互斥和风控门禁也全部通过。

登录或页面状态未就绪时，不创建工作流、不创建扫描记录、不启动扫描子进程，也不对 BOSS 执行导航、点击或刷新。

## 3. 非目标

本次不做以下改动：

- 不自动填写、提交或绕过 BOSS 登录；
- 不在登录完成后自动开始扫描；
- 不自动修改用户设置的搜索筛选条件；
- 不改变关键词、匹配规则、模型、预算、配额或岗位数据；
- 不改变通信批次的确认与“开始沟通”双重授权；
- 不移除高级入口的 Edge Control 兼容模式；
- 不新增数据库表、字段或迁移。

## 4. 用户流程

### 4.1 正常启动

1. 用户双击 `Start.bat`。
2. RoleFlow 完成离线安装检查。
3. 启动或复用一个项目专用 Edge 窗口。
4. 启动本地工作台服务。
5. 在同一个项目专用 Edge 窗口中确保存在 BOSS 和工作台两个标签页。
6. RoleFlow 执行一次只读就绪检查。

### 4.2 第一次使用、尚未登录

1. `BOSS-SEARCH` 标签页保持为当前可见标签页，供用户手动登录。
2. 工作台标签页在同一窗口中保留。
3. 工作台状态显示“等待登录”，主继承模式按钮保持禁用。
4. 用户完成登录，并在 BOSS 中打开岗位搜索结果页、设置本轮筛选条件。
5. 用户切回工作台标签页。
6. 工作台轮询检测到登录和搜索页均有效，显示“继承模式已就绪”并启用“执行一轮”。

### 4.3 已经登录

1. 如果启动时已经处于有效 BOSS 搜索结果页，工作台标签页可作为启动完成后的当前标签页。
2. 工作台直接显示“继承模式已就绪”。
3. 用户仍需主动点击“执行一轮”，系统不会自动开始扫描。

### 4.4 登录有效但页面不正确

如果用户停留在首页、职位详情、聊天页或其他非搜索结果页：

- 工作台显示“请在 BOSS-SEARCH 打开岗位搜索结果页并设置筛选”；
- “执行一轮”保持禁用；
- 系统不自动导航回搜索页。

### 4.5 风控或安全验证

如果页面出现登录风控、安全验证或访问异常：

- 工作台显示独立的风控状态，不把它误报为普通未登录；
- “执行一轮”保持禁用；
- 系统不导航、不点击、不重试扫描；
- 用户完成验证后，由后续只读检查重新判断状态。

## 5. 浏览器窗口与标签页约束

项目继续使用一个 CDP 端点和一个项目 profile：

- CDP：`127.0.0.1:9222`
- Profile：`.runtime\edge-profile`

同窗约束如下：

1. 启动器先获得 `BOSS-SEARCH` 标签页的真实 `windowId`。
2. 如果工作台标签页不存在，通过 CDP `Target.createTarget` 创建，并验证其 `windowId` 与 `BOSS-SEARCH` 完全相同。
3. 如果创建后的窗口身份未知或不一致，关闭刚创建的标签页并让启动失败。
4. 不调用系统默认浏览器打开工作台。
5. 不创建第二个 Edge 窗口或第二个 BOSS 会话。
6. 后续通信阶段仍只允许在同一窗口创建承担 `BOSS-COMMUNICATION` 角色的第二个 BOSS 标签页。

工作台标签页不是 BOSS 标签页，因此正常启动时总标签页数量为两个；进入通信阶段后最多包含工作台、`BOSS-SEARCH` 和 `BOSS-COMMUNICATION` 三个标签页。

## 6. 就绪状态模型

新增一个不持久化的运行时状态模型：

| 状态 | 含义 | 主继承按钮 |
| --- | --- | --- |
| `browser_unavailable` | 项目专用 Edge 或 CDP 不可连接 | 禁用 |
| `boss_tab_missing` | 未找到可识别的 BOSS 标签页 | 禁用 |
| `login_required` | BOSS 页面存在，但登录无效 | 禁用 |
| `search_page_required` | 已登录，但不在岗位搜索结果页 | 禁用 |
| `risk_control` | 页面要求安全验证或处于访问异常状态 | 禁用 |
| `ready` | 登录有效且搜索结果页有效 | 可按原有门禁决定是否启用 |

接口只返回状态码、用户可读提示和检查时间，不返回完整 URL、筛选参数、DOM 文本、账号信息或 Cookie。

就绪状态不写入数据库。页面刷新、浏览器重启或标签页变化后，状态由下一次只读检查重新计算。

## 7. 组件边界

### 7.1 浏览器就绪检查器

新增一个独立的运行时组件，输入为浏览器适配器和 BOSS 站点适配器，输出为第 6 节的标准状态。

职责：

- 调用现有 `BossSiteAdapter.preflight()`；
- 将预期错误映射为稳定的就绪状态；
- 确认登录有效且 `isSearchPage=true` 后才返回 `ready`；
- 不执行导航、点击、滚动、刷新、数据库写入或平台筛选解析。

### 7.2 同窗标签页准备器

启动阶段使用独立组件：

- 查找项目专用 Edge 中的 BOSS 标签页；
- 查找或创建本地工作台标签页；
- 验证两者真实 `windowId` 相同；
- 根据首次检查结果选择启动后显示的标签页：
  - `login_required`、`search_page_required` 或 `risk_control`：显示 BOSS 标签页；
  - `ready`：显示工作台标签页。

标签页准备器不参与扫描或通信。

### 7.3 本地就绪接口

工作台新增只读接口：

```text
GET /api/browser-readiness
```

每次请求重新检查当前标签页状态，并返回标准状态。预期的未登录、页面不正确和风控均返回 HTTP `200`，由 `status` 字段表达；服务器自身故障才返回 `5xx`。

### 7.4 工作台门禁

主继承模式区域新增状态提示。页面脚本每 5 秒访问一次本地就绪接口：

- 初始状态按“检查中”处理，按钮默认禁用；
- 只有接口返回 `ready`，并且服务端渲染时的其他业务门禁也允许，按钮才启用；
- 浏览器状态再次失效时，按钮立即恢复禁用。

前端禁用只是用户体验门禁。`POST /api/workflow-run` 仍必须重新执行现有服务端预检，防止页面状态过期或请求绕过。

### 7.5 启动器

`scripts/start-workspace.ps1` 的职责顺序调整为：

1. 离线安装检查；
2. 启动项目专用 Edge；
3. 启动并确认工作台健康；
4. 调用项目自己的标签页准备命令，在同一个 Edge 窗口打开工作台；
5. 不再使用 `Start-Process http://127.0.0.1:8787/` 调用系统默认浏览器。

## 8. 错误处理与安全边界

- CDP 断开：返回 `browser_unavailable`，不自动切换 Edge Control。
- BOSS 标签页缺失：返回 `boss_tab_missing`，不创建第二个 BOSS 会话。
- 登录无效：返回 `login_required`，由用户手动登录。
- 非搜索页：返回 `search_page_required`，由用户手动打开搜索页。
- 风控页：返回 `risk_control`，立即保持所有继承操作禁用。
- 工作台标签页跨窗：关闭本次创建的工作台标签页并让启动失败。
- 就绪轮询失败：按钮保持禁用；不使用最后一次成功结果继续执行。
- 页面状态在点击后变化：服务端现有预检拒绝创建工作流或启动扫描。

轮询只执行本地 CDP 命令和当前 DOM 读取，不调用 BOSS 网络接口，也不刷新页面。5 秒间隔不受岗位扫描访问预算控制，但页面关闭或风控出现时必须立即反映为非就绪。

## 9. 测试策略

### 9.1 单元与适配器测试

- 未连接浏览器映射为 `browser_unavailable`；
- 无 BOSS 标签页映射为 `boss_tab_missing`；
- 未登录映射为 `login_required`；
- 非搜索页映射为 `search_page_required`；
- 风控映射为 `risk_control`；
- 登录且搜索页有效映射为 `ready`；
- 状态输出不包含 URL、Cookie、账号或 DOM 文本。

### 9.2 同窗测试

- 已有同窗工作台时复用，不重复创建；
- 工作台缺失时以 `BOSS-SEARCH` 为 opener 创建；
- 新工作台 `windowId` 不一致或未知时关闭并失败；
- 未登录时激活 BOSS 标签页；
- 已就绪时激活工作台标签页；
- 不创建新 Edge 窗口。

### 9.3 工作台测试

- 就绪接口对六种状态返回稳定 JSON；
- 主继承按钮初始禁用；
- 只有 `ready` 能解除浏览器门禁；
- 原有资料、计划、匹配卡、运行互斥或风控门禁不能被前端轮询覆盖；
- `POST /api/workflow-run` 继续执行服务端预检。

### 9.4 启动契约测试

- 启动器不再调用系统默认浏览器打开工作台；
- 启动器调用同窗标签页准备命令；
- Edge Control 不会被启动或作为回退；
- Windows PowerShell 5.1 中文提示编码继续受 BOM 测试保护。

### 9.5 回归

- 全部离线检查通过；
- 真实验收时先用未登录 profile 验证“等待登录”；
- 用户登录并打开搜索页后验证工作台变为“已就绪”；
- 未经用户点击不创建扫描；
- 实际沟通仍需要确认清单和再次点击“开始沟通”。

## 10. 验收标准

以下条件全部满足才视为完成：

1. 双击 `Start.bat` 后只有一个项目专用 Edge 窗口。
2. 工作台和 BOSS 位于该窗口的不同标签页。
3. 第一次未登录时，用户能够在 BOSS 标签页完成登录，工作台不能启动继承模式。
4. 登录但非搜索页时，工作台继续禁用并给出正确提示。
5. 登录且搜索页有效时，工作台自动更新为就绪并允许用户点击“执行一轮”。
6. 系统不会因登录成功自动扫描。
7. 风控、页面丢失或浏览器断开时，门禁立即恢复为禁用。
8. 前端状态无法绕过服务端预检。
9. Edge Control 始终不需要启动。
10. 完整离线测试和最终分支审查通过。
