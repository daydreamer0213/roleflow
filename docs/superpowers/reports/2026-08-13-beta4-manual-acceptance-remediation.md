## 健壮性调整

安全门没有删除，但把“页面变化”分成两类：

- 登录失效、风控、目标不一致、点击后结果不明等可能造成账号风险或重复沟通的情况，继续立即停止。
- 进程中断、绑定可恢复、点击前短暂读取失败等不会造成外部写入的情况，允许从持久化检查点恢复或做一次受限重试。
- 工作流轮询数据损坏时，错误会在折叠区外直接显示并暂时禁用控制；后续有效快照到达后自动恢复。暂停、待确认和中断状态把恢复操作放在手机首屏。

这样可以容忍普通中断和安全范围内的页面波动，同时不把“更健壮”变成“风险信号也继续点”。

2. 真实消息抽样：新账号消息为空；出现真实会话后再少量只读抽样。
3. 薪资“区间只要有重合就保留”的精细规则：会改变召回与推荐分布，需先用新基线量化再由用户决定。
4. `generated` 筛选计划是否冻结：当前已把它降到非主流程说明，不做删除或架构推翻。
5. 许可证：当前仓库为 `AGPL-3.0-only`，允许商业使用，不满足“禁止他人盈利”的目标；需用户选择许可证策略。
6. 对外发布：安装向导当前为英文，RoleFlow 安装包未代码签名；新电脑还需要可再分发的 Edge Control 安装来源和许可结论。
7. Inno Setup 商业发布许可、版本号与发布说明，需要在正式商业分发前确认。
8. `search_page_api` 继续作为后续独立拓展，不进入当前主线验收。
