- 安装器 `DefaultDirName={localappdata}\Programs\RoleFlow` 本身不含版本号，`UsePreviousAppDir=yes` 正常保留用户以前选择的位置。
- 诊断时 Windows 安装记录 DisplayVersion 为 1.3.1，InstallLocation 为 `D:\DevData\RoleFlow-first-use-acceptance\v1.2.0\app\`；实际安装目录 package.version 同样是 1.3.1。旧文件夹名称不代表安装了旧代码。
