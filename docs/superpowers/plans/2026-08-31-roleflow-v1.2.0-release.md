# RoleFlow v1.2.0 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 从当前已验证的 `main` 生成、发布并回查 RoleFlow v1.2.0 标准安装器和便携包。

**Architecture:** 复用现有 `package-release.ps1`、`build-installer.ps1` 和标签触发的 `release.yml`。本地只更新版本元数据与发布说明、验证同一候选提交；GitHub Actions 在最终标签提交上重新测试、构建三个资产并发布 Release。

**Tech Stack:** Node.js 22.23.1、PowerShell 5.1+、Inno Setup 6、Git、GitHub Actions、GitHub Releases。

## Global Constraints

- 版本号、标签、安装器文件名和发布说明统一为 `1.2.0` / `v1.2.0`。
- 大型构建缓存与验收产物保存在 `D:\DevData`，不写入系统盘或 Git。
- 发布包不得包含简历、API Key、BOSS 登录资料、SQLite 数据库、浏览器 profile、日志或 Edge Control bridge。
- 标签只在精确候选提交的完整离线门禁、便携包和安装器验证通过后创建。
- 禁止强制推送；标签工作流失败时保留现场，先诊断，不替换已发布资产。
