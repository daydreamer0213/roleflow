# RoleFlow v1.2.2 Release Implementation Plan

**Goal:** 从已经推送并验证的 `main` 生成 RoleFlow v1.2.2 修复候选版，完成本地安装包与便携包门禁，并为用户真实验收准备隔离环境。

**Architecture:** 复用现有 `package-release.ps1`、`build-installer.ps1` 和标签触发的 `release.yml`。本地候选构建与公开发布分开：先在精确候选提交上验证版本元数据、完整离线门禁、便携包、安装器和隐私排除；只有再次明确进入正式发布时才创建并推送 `v1.2.2` 标签。

**Tech Stack:** Node.js 22.23.1、PowerShell 5.1+、Inno Setup 6、Git、GitHub Actions、GitHub Releases。

## 全局约束

- 版本号、候选安装器和便携包统一为 `1.2.2` / `v1.2.2`。
- 本补丁只收口暂停/筛选恢复、卡片上限和可读错误，不改变数据库格式、模型策略或 BOSS 权限边界。
- 大型构建产物放在 `D:\DevData\RoleFlow-release-v1.2.2`，不写入系统盘或 Git。
- 发布包不得包含简历、API Key、BOSS 登录资料、SQLite 数据库、浏览器 profile、日志、报告或 Edge Control bridge。
- 自动验证只使用 fixture、假浏览器和临时数据库，不访问真实 BOSS，不执行填写、发送、投递或申请。
- 推送 `v1.2.2` 标签会自动公开发布，必须在本地候选门禁完成后作为独立步骤执行。
