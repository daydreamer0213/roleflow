# RoleFlow v1.3.0 Release Implementation Plan

**Goal:** 把已经完成页面验收的四组功能合并进 `main`，在精确提交上完成本地与云端发布门禁，公开 v1.3.0，并把公开安装器下载到 D: 供用户独立完成最后一轮真实人工验收。

**Architecture:** 复用现有 `package-release.ps1`、`build-installer.ps1` 和标签触发的 `release.yml`。先完成快进合并与完整离线检查，再建立版本候选、构建本地证明包并检查隐私边界；最后推送精确 `main` 和注释标签，由 GitHub Actions 重新测试、构建并原子公开三个资产。

**Tech Stack:** Node.js 22.23.1、PowerShell 5.1+、Inno Setup 6、Git、GitHub Actions、GitHub Releases。

## 全局约束

- 版本号、候选安装器和便携包统一为 `1.3.0` / `v1.3.0`。
- 大型构建产物只放在 `D:\DevData\RoleFlow-release-v1.3.0`，不写入系统盘或 Git。
- 发布包不得包含简历、API Key、BOSS 登录资料、SQLite 数据库、浏览器 profile、日志、报告或 Edge Control bridge。
- 自动验证只使用 fixture、假浏览器、纯渲染和临时数据库，不访问真实 BOSS，不执行填写、发送、投递或申请。
- 最后一轮真实人工验收由用户独立完成；本次任务只下载并核对公开安装器，不启动真实验收流程。
- 推送 `v1.3.0` 标签会自动公开发布；标签只在本地候选门禁全部通过后创建，失败时不移动或覆盖标签。
