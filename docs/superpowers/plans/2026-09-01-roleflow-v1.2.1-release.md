# RoleFlow v1.2.1 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 从已合并并验证的 `main` 生成、发布并回查 RoleFlow v1.2.1 标准安装器和便携包。

**Architecture:** 复用现有 `package-release.ps1`、`build-installer.ps1` 和标签触发的 `release.yml`。本地只更新版本元数据与发布说明，并在同一候选提交上验证完整离线门禁、便携包和安装器；最终注释标签 `v1.2.1` 触发 GitHub Actions 在精确标签提交上重新测试、构建三个资产并发布 Release。

**Tech Stack:** Node.js 22.23.1、PowerShell 5.1+、Inno Setup 6、Git、GitHub Actions、GitHub Releases。

## Global Constraints

- 版本号、标签、安装器文件名和发布说明统一为 `1.2.1` / `v1.2.1`。
- 本次按补丁版发布首次使用、恢复可靠性和轮次操作体验改进，不改变数据库格式或 BOSS 权限边界。
- 大型构建缓存与验收产物保存在 `D:\DevData\RoleFlow-release-v1.2.1`，不写入系统盘或 Git。
- 发布包不得包含简历、API Key、BOSS 登录资料、SQLite 数据库、浏览器 profile、日志或 Edge Control bridge。
- 标签只在精确候选提交的完整离线门禁、便携包和安装器验证通过后创建。
- 禁止强制推送；标签工作流失败时保留现场并诊断，不替换已经发布的资产。
- 自动验证只使用 fixture、假浏览器和临时数据库，不访问真实 BOSS 或产生外部沟通。
